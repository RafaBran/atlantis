# Frontend

Interface em Angular 22 com Angular Material (tema azure-blue, Material 3).

## Pré-requisitos

- Node 24 (requisito do Angular 22: `^24.15.0`). O Node instalado na máquina já atende.
- As dependências ficam em `node_modules/`, dentro deste projeto. Nada é instalado globalmente.

## Comandos

```bash
npm install     # instala as dependências do projeto
npm start       # sobe o servidor de desenvolvimento em http://localhost:4200
npm run build   # gera a versão de produção em dist/
```
