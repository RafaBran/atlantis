# Atlantis

Plataforma web para organizar e acompanhar a preparação para concursos públicos — antes e depois da publicação do edital.

## Status

Fase de especificação. O documento de referência é [`especificacao_plataforma_preparacao_concursos.md`](especificacao_plataforma_preparacao_concursos.md).

## Stack prevista

- **Frontend:** Angular + TypeScript, Bootstrap
- **Backend:** Java + Spring Boot
- **Banco de dados:** PostgreSQL, com migrações via Flyway
- **Ambiente:** Docker
- **IA:** integração desacoplada do núcleo do sistema
